## COMMANDS

### CLI Commands
1. pwd : it shows you your current or present working directory ie. where you are on the terminal
2. start . : it opens the directory you currently are in
3. ls : it lists all the files and directories
4. ls -la : it lists all files, hidden files and directories
5. cd : change directory or folder
6. cd .. : go back out of a folder or directory by one level
7. cd ~ : go to the system home folder or directory
8. touch file.txt : create a file
9. rm file.txt : delete a file permanently
10. mkdir file : to create a directory or folder
11. rm -rf file : delete a folder permanently
12. code . : opens folder or file in vscode
13. crtl l : clears terminal
14. crtl c : kills the existing process on the terminal
15. tab : auto-completes your command
16. mkdir -p folder1/folder2 : creates folder2 inside folder1 ie. a folder inside another folder
17. cd folder1 && touch file.txt : it runs two commands at once. one after the other

### Git Commands
1. git init: initializes git inside a folder
2. git config --global user.name "Name"
3. git config --global user.email "email"
4. git add (filename) 
5. git push : link up a repo with git hub
6. git commit -m "commit message" : leave a note on your code and create a local repository
7. git status : to check current file or folder status with git
8. git branch -M main : to make the main brach the master
9. git checkout -b branch-name/what-it-is-about
10. git switch branch-name or git checkout branch-name : to switch between branches
11. git branch : lists all git branches
